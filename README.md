## Projects

### Project 01 — B2B SaaS Cloud Infrastructure

**Technologies:** AWS, Terraform, VPC, EC2, RDS MySQL, IAM, Security Groups

Designed Terraform configurations for a growing B2B SaaS company's cloud infrastructure.

Key components:
- Custom VPC in the Frankfurt Region (`eu-central-1`)
- Public and private subnets across two Availability Zones
- Internet Gateway and public routing
- EC2 instance configuration using Amazon Linux 2023
- Private RDS MySQL database configuration
- Security group isolation and IAM-based instance management

**Status:** Terraform configuration validated locally. AWS deployment and runtime testing pending.
